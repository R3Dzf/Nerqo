Nerqo native 1.0.1 — development build

This iteration adds matching Windows/Android Transfers, Devices and Settings,
a unified vector icon, persistent light/dark appearance, Windows file/folder
drag-and-drop, visible operation feedback, and verified completed-file retry
for Windows-to-Android folders.

The native clients use WPF and Compose. The legacy browser implementation is
retained only for regression tests and is not shipped in the native installer.

Not yet an official Stable release. Native CI validation, permanent Android
release signing, physical-device transfer and in-place upgrade checks must be
reported separately. A Debug APK cannot update the permanent-key installation.
Wi-Fi Direct and Bluetooth are not implemented. Windows Authenticode signing
is not present. See docs/NATIVE_ROADMAP.md for all nine phases.
