# Nerqo 1.0.6 Stable

- Android QR scanning uses a dedicated portrait activity.
- Android accepts secured Wi-Fi QR codes (Android 10+) with an explicit Android
  network approval. On supported Windows 11 versions, open Devices → Laptop
  hotspot setup, enable Mobile hotspot and scan the Wi-Fi QR shown by Windows.
  Then return to Nerqo, refresh its addresses and scan its pairing QR.
  Older Windows releases without a Wi-Fi QR use the normal Wi-Fi settings path.
- Both apps expose Disconnect. It revokes only the selected peer token, keeps
  the Wi-Fi network connected and requires pairing again. Unfinished downloads
  retain local checkpoints; uploads bound to an old token may need restarting.
- Automatic Android list refresh is silent, retains operation feedback and
  updates items only when changed. It does not enter the global busy state.
- A Wi-Fi connection requested by the user is retained for local traffic.
  When the phone itself hosts the hotspot, unrelated client Wi-Fi is not forced.

The laptop-hotspot shortcut uses Windows settings; Nerqo does not create a
Windows hotspot by itself or guarantee hotspot/QR support on every laptop.
5 GHz remains selectable in system hotspot settings where supported. An
in-app Android frequency selector and separate persistent transfer history
remain future work. Physical hotspot joining and camera rotation on a real
phone still require device acceptance testing; emulator transport tests do
not substitute for those checks.

Windows and Android retain the permanent Android signing identity, coordinated
version 1.0.6, verified deltas from 1.0.5 where eligible and full-update fallback.
