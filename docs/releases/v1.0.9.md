# Nerqo 1.0.9

Update both Windows and Android for coordinated connection controls.

## Implemented

- Android file and folder execution belongs to a private `dataSync` foreground
  service, with a notification showing Sending/Receiving, file name, percentage,
  transferred bytes, measured speed and ETA; Pause/Resume/Cancel actions and
  retained Paused/Interrupted/Completed/Cancelled outcomes;
  bounded CPU/Wi-Fi locks and Android 15 timeout handling. Closing/recreating the
  Activity does not interrupt its transfer worker or the application's Wi-Fi
  request. After process death/force-stop, the saved job still needs explicit
  Resume. No transfer starts from boot or without a user action.
- Disconnect suspends access while retaining the same pairing token and upload
  ownership. Reconnect restores it; Forget explicitly revokes/removes access.
  On Android, selecting a discovered/private IP verifies its saved certificate
  before sending credentials. A paused job can move to a new address only with
  the same certificate, retaining its original checkpoint and receipt scope.
- Verified Android downloads queue durable delivery acknowledgements before
  clearing the saved job. Bounded rotating retries run after completion and on
  later successful connections. Windows validates the item/size/hash/session and
  deduplicates acknowledgements. Deleted/expired shares cannot be reconstructed
  into Windows history from an acknowledgement alone.
- Windows shows measured outgoing socket progress and saved incoming offsets,
  speed estimates, per-file ETA and Pause/Resume/Cancel controls. After resuming
  on Windows, press Resume on Android. Completed socket writes remain Awaiting
  verification until Android confirms its SHA-256 check. Folder progress is per
  member; no aggregate Windows folder ETA is claimed.
- Optional Fast file sharing hashes and holds the original read-only instead of
  making a second copy. It still needs a complete checksum pass before sharing.
  These shares last until Exit; original files cannot be edited/deleted while
  Nerqo holds them. Default snapshot shares retain their existing independent,
  persistent behavior. Preparation can be cancelled.
- Windows History can open a recorded local path, show it in Explorer and clear
  the log without deleting files. Android History retains retry details, shows
  actual upload names, opens saved document destinations and retries paused,
  interrupted or cancelled jobs. Saved grants/providers and the original peer
  must remain accessible. Older entries may not have retry/open metadata.
- Android 16-compatible phones can request the 5 GHz local hotspot band through
  the public channel configuration API. Auto remains available on older phones.
  The device/regulatory environment may refuse the request. Confirm the actual
  connected band on the laptop; this is not a physical radio benchmark.

## Validation and limits

Publication requires native Windows transport/integrity/range/control tests,
Android TLS/SAF instrumentation and actual 64 MiB screen-off uploads/downloads
with notification action and final SHA-256 acceptance,
coordinated permanent-key APK verification, and previous-version installer
replacement/delta reconstruction. Individual development runs are not releases.

No access to the user's physical phone/router/laptop is available here. Long
Doze/battery-vendor behavior, 700 MiB throughput, radio band negotiation and
physical sleep/network-switch cases still require that hardware. Android limits
`dataSync` background time; the service pauses and retains checkpoints when the
OS timeout arrives. Force-stop never promises continuous transfer.

Windows hotspot creation/band changes continue through system Settings; the
Wi-Fi QR is available only on supported Windows versions. Older Android phones
use system settings to select 5 GHz. Wi-Fi Direct and Bluetooth transports are
not included. Windows still has no trusted Authenticode publisher certificate.
The existing installer identity, per-user location, cached delta bases and
permanent Android signing certificate are retained.
