# Nerqo 1.0.7 Stable

## Smaller future Windows deltas

The Windows installer no longer applies outer solid LZMA compression to the
already compressed .NET single-file payload. Keeping stable payload bytes
unchanged allows the existing NRQDEL01 updater to reuse them across releases.
The full installer can be larger; this is a deliberate tradeoff for reusable
future update bytes. No .NET runtime download or new patch reader is required.

The transition from the old compressed 1.0.6 installer may require a one-time
full download. Only a real measured delta is published when it saves space;
no small migration size is promised. The Windows CI regression gate repackages
the actual 1.0.6 program files with the new packaging, compares them with 1.0.7,
requires a delta below 5% of the target, and verifies exact SHA-256 reconstruction.
That test baseline is not the public 1.0.6 installer.

## Replace the existing installation

The installer retains the original application ID and per-user architecture,
reuses the previous installation folder, closes Nerqo through Restart Manager,
and overwrites its program files. It does not launch a second installed copy.
Received files, paired devices, settings and TLS identity remain outside the
program folder and are preserved. Updating can interrupt an active transfer;
its saved checkpoints remain available subject to the existing resume limits.

Manual and in-app installations cache their exact installer bytes for the next
delta base. At startup, obsolete versioned installer caches are removed. The current
version's installer is retained as the next delta base, as are staged future
updates and unrelated files. Delta reader operation buffers are allocated once
rather than repeatedly on the stack for large patches.

Windows and Android remain on coordinated version 1.0.7 with the permanent
Android signing certificate and full/delta integrity checks. Physical-device
acceptance, trusted Windows Authenticode signing and the previously documented
radio/UX limitations remain outstanding.

## Packaging regression measurement

The development Windows runner measured 214,674 bytes for the repackaged 1.0.6
payload → 1.0.7 installer test, against a 92,883,577-byte full installer (0.2311%).
SHA-256 reconstruction and running-process replacement passed. The Stable
workflow repeats the same measurement on the final build and additionally
checks previous-folder discovery without supplying an installation directory.
This measurement does not describe the old-format public 1.0.6 migration patch.
