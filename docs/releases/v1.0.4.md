# Nerqo 1.0.4 Stable

Install both native apps together, or check for updates from Settings in 1.0.3.
Android retains the permanent release signing identity.

## Windows changes

- Checks Windows Firewall permissions before starting its listener. When private-network rules are
  missing, the first-run dialog offers to allow local sharing. The **Allow private
  network access** button requests Windows administrator approval (UAC); only
  executable-specific inbound TCP 44888 and UDP 44889 rules for the Private profile
  and LocalSubnet are added. No console is opened, and the receiver keeps running
  without administrator rights.
- Rechecks permissions after approval and provides Check again / Windows Firewall
  settings. An explicit block or managed policy is reported for manual review.
  Firewall protection, public access and network classification are not changed.
- Detects a Public connection after the private rules are ready and offers Windows
  network settings, so a trusted home Wi-Fi/hotspot can be marked Private by you.
- Replaces the default appearance checkbox with a theme-aware switch: clear on/off
  position and contrast, keyboard focus, accessible Toggle state, immediate theme
  changes and persistent preference. Unreadable preferences no longer stop startup.

## Updates and validation

Full native installers and compatible deltas from 1.0.3 are included when smaller
than the full package. Every published delta is reconstructed and SHA-256 checked
against the full target before publication. Missing or incompatible update bases
use the verified full-download fallback.

Windows CI exercises the actual Firewall COM API to add/read/remove narrowly
scoped test rules on a disposable runner. The native UI smoke toggles appearance
through the accessibility Toggle provider in both directions, checks resource colors
and persisted preferences, and captures light/dark Settings screens. Release gates
also cover encrypted transport, Windows installer upgrade with retained identity
and data, Android build/JVM tests, emulator recovery and permanent APK signing.
The secure-desktop UAC click and physical-device interoperability still require
user-device acceptance; CI does not certify every router or Windows policy.

## Downloads and scope

- Windows 10/11 x64: **Nerqo-Windows-Setup.exe** (self-contained per-user installer).
- Android: **Nerqo-Android.apk** (permanent-key release build).
- Integrity metadata: **SHA256SUMS.txt** and **update-manifest.json**.

LAN/Wi-Fi and normal hotspot sharing remain the supported transports. Native Wi-Fi
Direct and Bluetooth are not included. Windows still lacks a publisher-trusted
Authenticode signature. See [1.0.3 release notes](v1.0.3.md) for transfer behavior
and the remaining physical-device validation matrix.
