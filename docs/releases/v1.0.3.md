# Nerqo 1.0.3 Stable

Native Windows and Android apps for sharing files, folders, text and links over
a private local network. Install both platforms from this release.

## Downloads

- **Windows:** `Nerqo-Windows-Setup.exe` — Windows 10/11 x64, self-contained per-user installer.
- **Android:** `Nerqo-Android.apk` — permanent release signing identity.
- **Verification:** `SHA256SUMS.txt` and `update-manifest.json`.

## Included

- Matching native Transfers, Devices and Settings screens, light/dark appearance,
  Windows tray and file/folder drag-and-drop. No browser or terminal required.
- Offline local HTTPS transfers with QR pairing, certificate pinning, device
  discovery and manual private IP entry. Normal Wi-Fi and phone hotspot networks
  are supported; use a 5 GHz network when the devices and access point allow it.
- Nested folders and empty directories without ZIP staging; chunk and complete-file
  SHA-256 checks; saved Android jobs and explicit Pause / Resume / Cancel.
- Interrupted downloads resume at verified 4 MiB checkpoints with seekable storage.
  Nonseekable providers restart the active file. Verified folder members are
  preserved, and changed existing files are reported as conflicts.
- Retry after a lost upload-finish reply acknowledges the original completed file
  instead of publishing a duplicate. Automatic refresh no longer occupies the
  Android worker while a saved job awaits Resume.
- In-app Stable update checks, download verification, full installers and delta
  updates where a compatible previous published native package is available.

## Installation and upgrades

Run the Windows setup normally. Open the Android APK and allow installation for
the app used to open it. The installer updates an existing native Nerqo install;
Android updates require the same permanent signing certificate. Debug APKs use
a different signing identity. Versions 0.3.x used a legacy app: install both native
apps and pair again. A transfer already in progress should be completed or
cancelled before upgrading. Internet is needed for update downloads, not LAN sharing.

## Validation

Release publication requires native Windows build/transport/UI checks, a Windows
1.0.1 → 1.0.3 installer upgrade preserving identity/pairing/data, 36 regression
cases, 15 Android JVM tests, five emulator TLS/SAF transport checks and Compose
Pause/Resume recovery with the saved file SHA-256 checked. Android signing and
application payload are independently verified. This records automated and
emulated validation, not certification on every physical device.

## Known limits

- Native Wi-Fi Direct and Bluetooth transports are not included. Use the same
  Wi-Fi or a normal phone hotspot. Nerqo does not force a radio band.
- Physical-phone lifecycle, external document providers, low-storage behavior,
  router/firewall interoperability and physical-device upgrades need wider testing.
  No physical 5 GHz throughput benchmark is claimed.
- Windows has no publisher-trusted Authenticode signature and may show an
  unrecognized-publisher prompt. Android uses the existing permanent release key.
- Clipboard synchronization and DNS-SD discovery are not included.

Stable is the release channel for the implemented LAN/hotspot feature set; the
remaining roadmap items above are not claimed complete.
