# Nerqo

**Send anything. Stay offline.**

Nerqo is a local-first project for transferring files, text and links between Windows and Android over a shared Wi-Fi network or a phone hotspot, without internet.

This repository contains the Python host, responsive web client, Android companion project and automated tests.

> Current status: **v0.1.0 early prototype**. Real-device testing, transport encryption, Wi-Fi Direct and Bluetooth are not yet implemented. Use only on trusted private networks.

See the source tree for setup and build instructions.
